# 骨牌造境

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## 地面塑形

场景面板中选择「抬高 / 压低」后，在桌面上拖动即可塑造缓坡、窄脊与凹槽；元件的支承高程会随地形自动贴合，不会悬空或沉入地面。窄于一枚骨牌的凸脊会显示为斜纹**不确定边界**：模拟不会把它当作可靠支承，也不会让链路看起来相连却悄悄穿过。回放事件带有支承高程，中断原因会指向具体地形（高差不足、地形阻断、不确定边界）。

```sh
npm run verify
```

验证地形与接触模型：宽缓坡、窄于一枚牌的凸脊、两片坡面相交处，以及塑形后支脚贴合与平地回归。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。
